# Hugeicons Stroke Rounded

This directory vendors the official free Hugeicons icon font for offline JavaFX
use. No npm or JavaScript runtime is required. Ant includes these resources in
the application JAR.

- Source: https://use.hugeicons.com/font/hgi-stroke-rounded.ttf?t=1788885671703
- Glyph mapping source: https://use.hugeicons.com/font/icons.css
- Retrieved: 2026-09-29 (CDN revision 1788885671703)
- Documentation and usage terms: https://hugeicons.com/docs/icons-for-web/quick-start
- License: https://hugeicons.com/license

The official documentation permits personal and commercial use without
attribution. The font remains a Hugeicons asset; it is not project-authored code.

`glyphs.properties` contains the hexadecimal Unicode code points used by Quizora.
Update the font and mapping together because code points belong to this revision.
Use `HugeIcon` in FXML graphics or `HugeIcon.attach(control, "edit-02")` in Java.
Keep the control's visible text and accessible label. Icons inherit the control's
text color, including hover and selected states.
